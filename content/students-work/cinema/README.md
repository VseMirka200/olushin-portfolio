# Кинотеатр — вариант 8

**Авторы:** Ильчук Дмитрий и Гельмель Александр.

Учебный веб-проект кинотеатра на Python (Flask) и SQLite. В архиве проекта представлены веб-страницы, стили, база данных, SQL-схема и ER-диаграмма.

## Запуск

1. Установите Python 3.10 или новее.
2. Распакуйте архив проекта и откройте терминал в папке с `app.py`.
3. Установите зависимости: `python -m pip install -r requirements.txt`
4. Запустите приложение: `python app.py`
5. Откройте `http://127.0.0.1:5000` в браузере.

В интерфейсе предусмотрены просмотр сеансов и возврат билетов. Для структуры базы данных см. `schema.sql`, для ER-диаграммы — файл `ER_диаграмма_кинотеатр.drawio`.

*Описание подготовлено по файлам предоставленного авторами архива «Кинотеатр.zip».*

# Библиотека — учёт книг и выдач

**Авторы:** Темиева Тамина Эминовна и Ковалевская София Юлиановна.

Учебное веб-приложение для библиотеки, написанное на Python 3.8+ с использованием стандартной библиотеки Python и SQLite.

## Возможности

- Каталог книг, поиск и учёт экземпляров.
- Работа с читателями.
- Учёт выдачи и возврата книг.
- Отслеживание просроченных выдач.
- Проверка доступности экземпляров и ограничения целостности базы данных.

## Содержимое исходного архива

- `app.py` — веб-сервер и приложение.
- `library.db` — SQLite-база данных.
- `schema.sql` — структура базы данных.
- `data.sql` — исходные данные.
- `queries.sql` — примеры SQL-запросов и транзакций.
- `library.drawio`, `er_diagram.png` — ER-диаграмма.

## Как запустить

1. Установить Python 3.8 или новее.
2. Распаковать исходный ZIP-архив в отдельную папку.
3. В терминале перейти в папку с `app.py`.
4. Выполнить `python app.py`.
5. Открыть в браузере http://127.0.0.1:8000.

Дополнительные библиотеки не требуются. Если файла `library.db` нет, программа создаст его на основе `schema.sql` и `data.sql`.

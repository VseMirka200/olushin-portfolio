## О проекте

Это персональный сайт-портфолио преподавателя КГБПОУ «Яровской политехнический техникум». Здесь собраны сведения о профессиональной деятельности, образовании, опыте работы, достижениях преподавателя и студентов, а также материалы учебных проектов.

Сайт опубликован с помощью **GitHub Pages** и доступен без регистрации. Репозиторий содержит исходный код страниц и размещённые на сайте материалы.

> **Примечание.** Сведения, документы и достижения на сайте отражают опубликованные материалы портфолио. Для получения актуальной информации обращайтесь к указанным первоисточникам; персональные и студенческие материалы следует использовать с учётом прав их владельцев.

## Технологии

Проект представляет собой **статический сайт** на HTML, CSS и JavaScript. Для его запуска не требуется база данных или серверная часть приложения.

| Компонент | Расположение |
| --- | --- |
| Главная страница | `index.html` |
| Дополнительные страницы | `pages/` |
| Стили | `assets/css/` |

| Документы и студенческие материалы | `content/` |

## Запуск локально

Для обычного просмотра достаточно современного браузера. Для разработки удобнее запустить локальный HTTP-сервер.

```bash
git clone https://github.com/VseMirka200/olushin-portfolio.git
cd olushin-portfolio
python -m http.server 8000
```

Затем откройте [http://localhost:8000/](http://localhost:8000/) в браузере. Для остановки сервера нажмите `Ctrl+C`.

### Проверка перед публикацией

Проверки файлов и JavaScript можно выполнить локально:

```bash
python scripts/check_site.py
node --check assets/js/main.js
```

Скрипт Python проверяет локальные ссылки HTML и соответствие файлов каталогам достижений; команда Node.js проверяет синтаксис JavaScript. Эти проверки не гарантируют отсутствие всех ошибок или уязвимостей.

В репозитории настроены GitHub Actions:

- [Проверка статического сайта](https://github.com/VseMirka200/olushin-portfolio/actions/workflows/check-site.yml) — ссылки, каталоги файлов и синтаксис JavaScript.
- [CodeQL security analysis](https://github.com/VseMirka200/olushin-portfolio/actions/workflows/codeql.yml) — автоматический анализ JavaScript на потенциальные уязвимости.
- [Публикация на GitHub Pages](https://github.com/VseMirka200/olushin-portfolio/actions/workflows/deploy-pages.yml) — развёртывание сайта.

Dependabot может создавать предложения по обновлению используемых GitHub Actions; **автоматическое слияние таких предложений отключено**. Решение о принятии обновлений остаётся за сопровождающим.

## Разработка и изменения

Основная ветка проекта — `main`. Для изменений рекомендуется создавать отдельную ветку и Pull Request, проверять результат работы сайта и дождаться успешного выполнения CI.

**Перед публикацией дипломов, сертификатов, фотографий или студенческих работ** необходимо убедиться, что их размещение согласовано с правообладателями и не раскрывает лишние персональные данные. Не добавляйте в репозиторий пароли, ключи доступа, токены и документы, не предназначенные для открытого распространения.

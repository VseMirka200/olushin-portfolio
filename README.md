Сайт объединяет сведения об образовании и профессиональном опыте преподавателя, личные достижения, результаты студентов и подборку выполненных ими проектов. Портфолио опубликовано на GitHub Pages и доступно без регистрации и установки.

## Разделы портфолио

- **Главная страница** — краткая информация о преподавателе, преподаваемых дисциплинах и месте работы.
- **Образование** — документы об основном образовании, профессиональной переподготовке и пройденных курсах.
- **Опыт работы** — сведения о текущем и предыдущих местах работы.
- **Достижения преподавателя** — сертификаты, дипломы и благодарности.
- **Достижения студентов** — сертификаты и дипломы обучающихся.
- **Работы студентов** — учебные проекты, выпускные работы, PDF-описания и архивы с исходными материалами.

## Возможности

- адаптивная вёрстка для компьютеров, планшетов и смартфонов;
- единая тёмная тема оформления;
- полноэкранный просмотр изображений и PDF-документов;
- фильтрация достижений по категории и периоду;
- сортировка материалов в галереях;
- скачивание архивов студенческих проектов;
- мобильное меню и управление интерактивными элементами с клавиатуры;
- отображение всех наград без обращения к сторонним API.

## Использование

Откройте **[опубликованную версию портфолио](https://vsemirka200.github.io/olushin-portfolio/)** в браузере. Для перехода между разделами используйте главное меню сайта.

Документы и изображения открываются во встроенном окне просмотра. В разделах достижений доступны сортировка и фильтры, а на странице студенческих работ можно открыть описание или скачать архив выбранного проекта.

## Локальный запуск

Проект не требует установки зависимостей или сборки. Клонируйте репозиторий и запустите любой локальный HTTP-сервер, например встроенный сервер Python:

```powershell
git clone https://github.com/VseMirka200/olushin-portfolio.git
cd olushin-portfolio
py -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

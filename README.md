## О проекте

**olushin-portfolio** — статический сайт-портфолио преподавателя. На сайте собраны сведения об образовании, опыте работы, достижениях преподавателя и студентов, а также примеры студенческих работ.

Сайт публикуется через GitHub Pages и не требует серверной части или сборки.

## Разделы сайта

- главная страница с краткой информацией;
- образование;
- опыт работы;
- достижения преподавателя;
- достижения студентов;
- работы студентов.

## Технологии

- HTML;
- CSS;
- JavaScript;
- GitHub Pages.

## Структура репозитория

```text
index.html            главная страница
assets/               стили, скрипты, изображения и другие ресурсы
content/              содержимое сайта
pages/                дополнительные страницы портфолио
service-worker.js     сервис-воркер сайта
README.md             описание проекта
```

## Запуск локально

Для просмотра достаточно клонировать репозиторий и открыть `index.html` в браузере:

```bash
git clone https://github.com/VseMirka200/olushin-portfolio.git
cd olushin-portfolio
```

Для корректной проверки путей и service worker удобнее запустить каталог через любой локальный HTTP-сервер.
